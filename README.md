## 8. Автоматизация и воспроизводимость

Для выполнения MLflow-части без Jupyter Notebook реализован `run_experiments.py`.

Скрипт:
1. Принимает Tracking URI, Dataset ID и ожидаемый SHA-256.
2. Загружает датасет из ClearML.
3. Проверяет SHA-256.
4. Создаёт train, validation и test выборки.
5. Создаёт MLflow Experiment при отсутствии или использует существующий.
6. Выполняет все шесть конфигураций.
7. Логирует параметры, метрики, теги и модели.
8. Проверяет полноту логирования.
9. Выбирает лучшую модель по validation F1.
10. Загружает модель из MLflow и проверяет совпадение предсказаний.
11. Рассчитывает и логирует тестовые метрики.

Повторный запуск создаёт новые runs внутри существующего эксперимента.

### Запуск в чистом окружении

Установка зависимостей:

```bash
poetry install
```

Проверка окружения:

```bash
poetry run python --version
poetry run python -m pip check
```

Для загрузки датасета необходим настроенный ClearML. При необходимости конфигурация создаётся командой:

```bash
poetry run clearml-init
```

Запуск экспериментов:

```bash
poetry run python run_experiments.py \
  --dataset-id 5cdf5d16eb0e4b018a11019bffe5a139 \
  --expected-sha256 724d80b05e39c7a72fe7631de59583c764049137f9d7089b01b5460e212c75c0
```

Для просмотра экспериментов локально:

```bash
poetry run mlflow ui --backend-store-uri sqlite:///mlflow.db --host 127.0.0.1 --port 5000
```

Интерфейс MLflow доступен по адресу `http://127.0.0.1:5000`.
